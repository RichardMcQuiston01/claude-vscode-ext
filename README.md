# Claude GUI Editor

## Overview

VSCode extension with GUI for editing Claude's settings JSON file(s)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 20+ and npm
- Visual Studio Code

### Installation

```sh
npm install
```

Installs both the extension host dependencies and the `webview-ui`
dependencies.

### Usage

```sh
npm run build   # build the extension host and the webview bundle
npm run watch   # rebuild both on change
npm run lint    # lint the extension host and the webview-ui app
```

Press `F5` in VS Code to launch the Extension Development Host and try the
extension.
